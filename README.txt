This repository holds files and instructions relevant to a forthcoming paper on the use of QGIS with Landsat images to track Industrial and Urban development.

To read more about how to use the files and trial the methodology see the 'How to use Landsat with QGIS' file.

Landsat Images are downloaded from USGS Earth Explorer
